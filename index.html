01 • AUTOMAÇÃO COMERCIAL

Enriquecedor B2B Pro

Para que serve?

Empresas costumam ter listas apenas com nomes ou domínios, mas precisam descobrir quem são os profissionais responsáveis por decisões comerciais e como contatá-los.

O que desenvolvi

Uma aplicação que processa empresas em lote, pesquisa decisores, analisa domínios e organiza informações corporativas em um painel de acompanhamento.

Python · automação · pesquisa web · SQLite · enriquecimento de dados
02 • ENGENHARIA DE DADOS

Banco Previdenciário

Para que serve?

Bases públicas muito grandes podem ser difíceis de abrir, organizar e consultar em ferramentas comuns. O projeto transforma esses arquivos em uma estrutura local preparada para análise.

O que desenvolvi

Pipeline de ingestão, padronização e validação de grandes volumes de dados, dividido em etapas claras: dados brutos, preparação, Parquet, banco de dados e exportações.

Python · DuckDB · SQL · Parquet · ETL/ELT · processamento em lote
03 • PRODUTO DIGITAL B2B

E2R2 Inteligência Comercial

Para que serve?

Profissionais que prospectam empresas em feiras precisam encontrar e adquirir listas organizadas sem depender de processos manuais.

O que desenvolvi

Uma plataforma web com catálogo de listas, busca, filtros, demonstrações, pacotes, área do usuário e recursos voltados à operação comercial.

Desenvolvimento web · UX/UI · dados · lógica de negócio · produto digital
